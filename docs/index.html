The question

Does learning longer-term action value add anything beyond immediate verifier rewards?

An outcome-grounded learning loop

Edit. Verify. Learn.

01 / ENVIRONMENT

Port a neural network

An agent edits a PyTorch implementation against a JAX reference. Checks cover topology, parameters, intermediate values, end-to-end parity, and determinism.

02 / CREDIT ASSIGNMENT

Measure what an action enables

Sample actions at the same code state, then measure eventual success across frozen-policy continuations. A small CPU critic learns these empirical action values.

03 / POLICY UPDATE

Learn from verified outcomes

RLOO-style updates train LoRA adapters with terminal reward, diagnostic penalties, and action-value credit. Verifier-filtered teacher corrections enrich collection.

What we can claim today

A working pilot, not a benchmark victory.

Training successes show that some agents can correct runtime and shape errors. They do not establish held-out improvement or causality. The critic dataset remains small, earlier integrity audits need investigation, and training feedback changed across the pilot. Controlled evaluation and reward ablations are the next step.
